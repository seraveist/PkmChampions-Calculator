# 상성표 개선 — 2026-09-13

상성표는 선택한 내 파티의 방어 상성과 공격 기술 타입 분포만 보여준다. 특정 상대 목록을 근거로 위험·안전 여부를 판단하지 않는다.

## 반영 사항

- 고정 상대 목록 파일, 상대별 평가 패널, 등급 계산, 빌드 데이터 및 역계산 Worker 전달 항목을 제거했다.
- 방어 상성의 합산 점수를 약점 / 반감 / 무효 마릿수로 교체했다. 1마리부터 18개 타입 표를 표시한다.
- 타입 무효와 부유·저수 등 특성 무효를 유지하고, 두꺼운지방·내열·수포·정화의소금·건조피부·필터 등 타입만으로 결정 가능한 특성 보정을 반영했다. 배율과 적용 특성명을 함께 표시한다.
- HP, 물리/특수, 접촉 등에 의존하는 특성 효과는 정적 표에서 제외하며 해당 특성 선택 시 안내한다. 도구·날씨·필드·상대 특성은 방어 표에 적용하지 않는다.
- 타점 체크는 실제 입력한 공격 기술의 타입별 보유 마릿수만 집계한다. 동일한 타입의 기술이 여러 개여도 한 마리로 센다. 기술 위력이나 상대별 효과는 평가하지 않는다.
- 날씨·필드 선택을 추가했다. 웨더볼·테레인펄스의 타입 변경을 먼저 적용하고 특성에 의한 타입 변환을 뒤에 적용한다. 테레인펄스는 타입과 특성에 따른 접지를 확인한다. 파티의 다른 포켓몬이 가진 특성을 동시에 적용하지 않는다.
- 기술 미입력 상태는 안내문이나 `—`로, 입력된 공격 기술에 특정 타입이 없는 상태는 `0`으로 구분한다. 입력한 포켓몬 수를 함께 표시한다.
- 미선택 슬롯에는 기술 입력 카드를 만들지 않는다. 슬롯 삭제 및 포켓몬 변경 시 잔존 기술이 집계되지 않도록 정리하고 배울 수 있는 공격 기술만 집계한다.
- 모바일 폼·특성 선택창의 잘못된 너비를 수정했다. 320px부터 선택값을 읽을 수 있는 공간을 확보했다.
- 기술 검색의 Enter 선택, 입력 포커스 유지, 지워진 기술의 타입 배지, 화면 교체 후 지연 입력 이벤트를 보완했다. 밝은·어두운 테마의 셀 대비도 수정했다.

## 검증

- 전체 회귀 1,364개 통과, 실패 0개, 기존 미지원 범위에 대한 건너뜀 16개. 최종 화면 보완 후 관련 구조·상태·배포 검사도 재확인했다.
- `npm run state:matchup`: 기존 폼·특성 상태 검사 17개와 새 동작 회귀 검사 11개.
- `npm run matchup:browser`: 실제 브라우저에서 키보드 선택, 날씨 변경, 미입력 상태, 슬롯 삭제, 1440/375/320px 화면과 양쪽 테마 접근성을 확인한다.
- `npm test`: 전체 메뉴의 구조·배포·데이터·계산·상태 회귀를 확인한다.
- 화면 검증 결과: [matchup-browser-verification.json](matchup-browser-verification.json).

수정 전 검토 및 관측 결과는 `matchup-menu-review.md`, `matchup-menu-review-probes.json`, `matchup-browser-review.json`에 역사적 기록으로 보존한다. 해당 기록에 있는 점수·상대 목록·삭제된 함수는 현재 사양이 아니다.
