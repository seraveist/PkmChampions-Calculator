# UI 세부 개선 검토 — 2026-09-14

이 기록은 전체 25개 성격 검색 단계의 검토다. 이후 요청된 입력·결과 축소와 10개 성격 검색 제한은 `reverse-compact-review.md`에 기록했다.

## 반영 범위

- 기본 본문 15px, 입력 값 15px(작은 화면 14px), 라벨 13px, 보조 설명 12px로 공통 글꼴 토큰을 정리했다. 밝은 테마의 보조 글자와 경고 색상은 대비를 높였다.
- 계산기·역계산·세부조정의 상태 선택을 공통 팝업으로 통일했다. 값과 목록은 중앙 정렬하고 화살표는 독립 배치한다. 기존 상태 값과 change 이벤트는 그대로 사용한다.
- 관측값 입력의 `입력 가능` 문구를 제거했다. 이 문구는 포켓몬 선택 여부를 알리는 표시였으며, 입력값 유효성 검사는 기존대로 유지한다.
- 역계산은 각 참가자의 HP·변화 상태·기술을 한 프레임에 배치한다. 내 포켓몬은 빨강, 상대는 파랑으로 구분하며 작은 화면에서는 세로 배치한다. 폭이 좁은 프레임은 피해 수치가 잘리지 않도록 KO 판정을 HP 실수치 옆에 배치한다.
- 스피드 비교의 `차이` 입력칸에 `+`를 표시한다. 입력값은 숫자를 유지하고 기존 표 제목과 비교 계산은 변경하지 않는다.
- 최속은 빨강, 준속은 파랑으로 표시한다. 적용은 보라, 현재 달성은 초록, 도달 불가는 빨강, 포인트 부족은 황갈색으로 구분한다. 현재 달성하면서 S 투자를 줄일 수 있으면 별도의 적용 버튼을 제공한다.
- HP 기준점은 기준·충족 여부, HP 전후·H 포인트 차이·적용, 짧은 효과를 보여준다. 상세 효과는 접었다 펼칠 수 있다. 기준 충족이 항상 더 좋은 배분이라는 의미는 부여하지 않는다.
- 도감의 종족값·특성·폼·상성·학습 기술에 공통 프레임을 적용하고 기술 목록에 행 구분선을 추가했다. 기술·특성·도구 팝업도 같은 프레임을 사용한다.

## 역계산 성능과 정확성

HP만 필요한 경로에서 전체 능력치 6개를 반복 계산하던 작업을 HP 전용 계산으로 분리했다. 두 번째 공격으로 관측 HP를 만들 수 없는 경우를 기존 계산 캐시로 먼저 확인한 뒤, 가능한 모든 경로를 기존 방식으로 검증한다. 후보 모집단, H32 우선순위, 대표 그룹 선택 및 다음 턴 판정은 유지한다.
