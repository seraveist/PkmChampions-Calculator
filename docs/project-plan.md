# Project Plan

이 문서는 `Pokemon Champions Calculator`의 전체 제품 기획을 정리한다.

## 프로젝트 정의

`Pokemon Champions Calculator`는 Pokemon Champions 룰과 데이터에 맞춘 배틀 보조 도구다. 핵심은 공격측과 방어측의 포켓몬 세팅을 입력한 뒤, 한 번의 공격이 방어측에게 주는 대미지를 빠르고 정확하게 계산하는 것이다.

현재 구현된 주요 기능은 다음과 같다.

- 대미지 계산기
- 포켓몬 도감
- 기술 도감
- 특성 도감
- 도구 도감
- 포켓몬 노력치 세부조정
- 내구 역계산

리팩토링의 우선순위는 대미지 계산기다. 대미지 계산기 탭의 상태 구조와 계산 로직이 안정화된 뒤, 세부조정과 내구 역계산을 다시 설계한다.

## 사용자 목표

사용자는 실전 배틀 준비 과정에서 다음 질문에 답하고 싶다.

- 이 포켓몬의 특정 기술이 상대 포켓몬에게 몇 퍼센트 들어가는가?
- 현재 랭크, 날씨, 필드, 특성, 도구를 반영하면 확정 몇 타인가?
- 특정 자동 진입 효과가 적용된 상황과 꺼진 상황을 쉽게 비교할 수 있는가?
- 상대의 남은 HP%를 보고 어떤 내구 조정이었는지 역산할 수 있는가?
- 포켓몬, 기술, 특성, 도구의 한글 정보를 빠르게 확인할 수 있는가?

## 핵심 기능 범위

### 대미지 계산기

최우선 기능이다.

- 공격측/방어측 포켓몬 선택
- 성격, 노력치, 랭크, 상태이상 설정
- 특성, 도구 설정
- 포켓몬 learnset 기반 기술 선택
- 기술별 위력 수동 입력
- 날씨, 필드, 벽, 방어, 진입 위험, 재앙 효과 설정
- 자동 진입 효과 적용
- 16개 난수 롤과 최소/최대 퍼센트 표시
- 확정/난수 N타 표시

### 도감

도감은 계산 로직보다 데이터 표시 기능에 가깝다.

- 포켓몬 한글명, 타입, 종족값, 특성, 기술폭 표시
- 기술 한글명, 타입, 분류, 위력, 명중, 설명 표시
- 특성 한글명과 설명 표시
- 도구 한글명과 설명 표시

도감은 대미지 계산기 리팩토링 이후, 데이터 품질과 검색 UX 중심으로 정리한다.

### 노력치 세부조정

현재 기능은 존재하지만, 대미지 계산기 탭의 상태 모델이 안정된 뒤 다시 개발한다.

향후 목표:

- 챔피언스 능력 포인트 시스템에 맞춘 실수치 계산
- 특정 공격/방어 조건을 만족하는 최소 투자량 탐색
- 속도, 내구, 화력 기준의 세부조정 후보 표시

### 내구 역계산

현재 기능은 존재하지만, 대미지 계산기 탭 정리 후 다시 설계한다.

향후 목표:

- 실제 게임에서 한 턴 공격 후 남은 HP%를 입력
- 가능한 방어측 노력치, 성격, 도구, 특성 후보 역산
- 날씨, 벽, 재앙, 특성 등 현재 대미지 계산기 조건 재사용

## 데이터 정책

기본 데이터는 Showdown 데이터가 source of truth다.

1. `smogon/pokemon-showdown` 또는 Champions mod 데이터에서 TS 파일을 주기적으로 동기화한다.
2. TS 파일에는 한글 텍스트가 없으므로 PokeAPI를 통해 한글명과 설명을 매칭한다.
3. PokeAPI는 갱신이 느리고 누락 데이터가 존재하므로 manual override로 보정한다.
4. manual override는 항상 마지막에 적용한다.

중요 원칙:

- Showdown 데이터는 계산과 데이터 구조의 기본값이다.
- 한글명/설명은 PokeAPI 자동 데이터보다 manual override를 우선한다.
- Champions mod 데이터에 custom 표시가 있더라도, upstream 업데이트로 반영될 수 있으므로 현재는 임의 삭제하지 않는다.

## 설계 원칙

- 계산 결과의 정확도를 UI 편의보다 우선한다.
- 다만 사용자가 실수하기 쉬운 자동 진입 효과는 자동화한다.
- 자동화된 값은 원본 입력값을 직접 바꾸지 않는다.
- 사용자가 수동으로 바꾼 값은 자동값보다 우선한다.
- 계산 근거 표시는 간단하게 유지한다.
- 상세 공식 설명 패널은 현재 목표가 아니다.
- 전체 행동 순서/우선도 판정은 핵심 기능이 아니다.
- 단순 실속도 비교로 충분한 조건은 자동 판정하되 UI에 명시한다.
- 테라스탈은 현재 Champions 룰상 비활성이지만, 차후 추가될 수 있으므로 구조적으로 남겨둔다.

## 제외 또는 보류 범위

현재 리팩토링 1차 범위에서 제외한다.

- 기술 우선도 기반 행동 순서 계산
- 트릭룸/우선도/차단 특성을 포함한 전체 선공/후공 시뮬레이션
- 전투 전체 시뮬레이션
- 이전 턴 피해량이 필요한 기술의 정밀 계산
- 랜덤 분기 기술의 전체 확률 트리 표시
- 세부조정/내구 역계산 재개발

보류 대상 예:

- `counter`
- `mirrorcoat`
- `metalburst`
- `comeuppance`
- `ficklebeam`

## 현재 상태 요약

현재 브랜치에서 대미지 계산기 리팩토링 준비가 진행되어 있다.

- 데이터 검증 스크립트 추가
- 대미지 골든 테스트 추가
- 자동 진입 효과 상태 테스트 추가
- source state / derived state 개념 정리
- 기술 위력 수동 입력 추가
- `calculateDamage()` 단계 함수 분리
- 기술/특성/도구/필드 메커니즘 데이터화 확대
- 계산 커버리지 매트릭스 자동 생성 추가
- 인수인계 문서 추가

## 성공 기준

대미지 계산기 1차 리팩토링 성공 기준:

- 사용자가 입력한 원본 상태와 자동 계산용 파생 상태가 섞이지 않는다.
- 자동 진입 효과가 직관적인 흐름으로 작동한다.
- 계산 엔진 변경 후 골든 테스트가 안정적으로 통과한다.
- Champions 데이터 동기화 후 누락/검토 항목을 문서로 추적할 수 있다.
- 다음 기능을 추가할 때 `calculateDamage()` 전체를 다시 뒤집지 않아도 된다.
