# 내구 역계산 리빌드

2026-09-09. 한 턴의 관측으로 형태를 좁히고, 결과 카드의 정보로 사용자가 다음 행동을 판단하는 흐름을 구현했다. 자동 추천이나 교체 시뮬레이션은 추가하지 않았다.

## 사용 흐름

1. 내 배치와 상대 포켓몬을 선택하고 시작 HP·랭크를 입력한다. 내 시작 HP는 실수치, 상대는 %다.
2. 실제 공방의 양쪽 기술, 상대 잔여 HP %, 내 잔여 HP 실수치, 선후공을 입력한다. 잔여 HP는 회복까지 끝난 턴 종료 기준이다.
3. 관측한 도구·특성이 있으면 선택한다. 미관측 도구는 현재 기술과 관련된 사용 가능한 도구를 자동 검토한다.
4. 형태 분석을 실행하면 H32 우선 후보를 표시한다. 대표 카드 하나를 먼저 펼쳐 보여 주고 다른 카드도 함께 펼칠 수 있다.
5. 대면이 바뀌면 ‘새 관측’을 누른다. 내 배치와 기술 목록을 보존하고 이전 관측·랭크·필드·결과·진행 중 분석을 정리한다.

날씨·필드·급소·장막과 추가로 알고 있는 상대 기술은 접힌 추가 설정에 둔다. 상대 추가 기술은 이번 턴의 피해 관측에 섞지 않고 결과 비교에만 사용한다.

## 결과 카드

- **예상 형태:** H32 우선 배분, 가능한 성격·특성·도구와 관측으로 좁힌 투자 범위. 대표 배분은 예시다.
- **다음 턴 시작 상태:** 양쪽 HP·최종 랭크·남은 도구와 발동한 상태 변화. 경로 일부에서만 가능한 변화는 별도로 표시한다.
- **내 기술들:** 후보별 대미지 실수치와 최대 HP 대비 %, 현재 잔여 HP 기준 적중 시 KO 분류, 비교 기술에 대한 선후공.
- **상대 관측 기술들:** 최대 네 개의 확인된 기술을 같은 기준으로 표시한다.

선후공 비교의 기본 기술은 관측한 기술이다. 사용자가 필요할 때 이미 입력한 내 기술 및 확인한 상대 기술 중 비교 기준을 바꿀 수 있다. 기술 우선도, 변화 후 속도, 필드를 사용하며 동속과 후보별 선후공 차이를 구분한다.

대미지는 잔여 HP로 잘라 표시하지 않는다. 양쪽 카드에서 각각 적중 시 KO가 가능하더라도 실제 행동 순서는 별도 표시된 선후공을 함께 봐야 한다. 다음 턴 시작 상태에서의 피해 범위를 제공하며, 그 턴 전체의 반격·피격 후 HP 변화를 자동 진행한 결과로 해석하지 않는다. 대검돌격처럼 다음 행동 때 해제되는 상태는 기술 조합의 순서를 반영한다.

## 계산 변경

관측 재현의 실제 HP 처리와 카드의 대미지 분포를 분리했다. 단일 기술 안의 연속 타격·피해 보정·열매는 기존 피해 엔진을 사용한다. 후보 그룹의 범위 계산에는 실제 구성원과 남은 포인트 제약을 사용한다.

가속의 턴 종료 상승을 추가했고 지구력·깨어진갑옷·모래성쌓기·열교환 등의 변화에 원인 표시를 연결했다. 증기기관·주눅, 관측한 약점보험·목스프레이, 확정 자기 강화·자기 회복 기술도 반영한다. 풍선·열매·노말주얼 소모, 전광쌍격의 타입 소실, 대검돌격의 피해 증가 상태를 다음 계산에 전달한다. 만나자마자·속이다 및 사용 후 전광쌍격은 다음 카드에서 재사용 불가로 표시한다.

턴 종료 처리를 중복 적용하지 않도록 했고, 관측된 변덕레이저 강화 여부를 다음 사용의 확정 조건으로 재사용하지 않는다. 미관측 도구의 피해 보정 없음 후보를 확인된 도구 없음과 구분한다.

상대 HP의 정수 %에 정확히 일치하는 후보가 없을 때만 ±1%p를 재검토한다. 근사 후보에는 표시를 붙이고 내 HP 실수치 조건은 완화하지 않는다. 0%·100% 관측은 이 자동 완화에서 제외한다.

## 성능

화면에 표시하지 않는 전체 후보 공방 요약은 기본 실행에서 제외하고, 실제 결과 카드에 해당하는 그룹을 계산한다. 전체 후보는 형태 추정 결과에 유지한다. 숫자가 같은 관측 경로를 재사용할 때에도 각 후보의 원래 성격·배분을 보존한다. 생명의구슬 반동의 가능한 HP 범위를 먼저 확인해 불가능한 경로를 일찍 제외하며, 최종 공방 대조는 그대로 수행한다.

같은 브라우저 검증 환경의 도구 미관측 사례에서 후보 35,414개를 유지하며 약 39.6초에서 10.2초로 단축됐다. 마지막 측정은 추정 약 8.8초, 카드 계산 약 0.14초이며 전체 시간에는 데이터 전달과 화면 갱신이 포함된다. 이 수치는 해당 입력·기기의 측정값이다.

## 적용 범위

내구 후보는 합의한 H32 우선 가정이다. H32 미만에 B/D를 투자한 모든 배분을 전수 탐색하지 않으며, 후보 수·정렬 점수를 실제 형태 확률로 표시하지 않는다.

미관측 도구는 관련된 도구를 자동 탐색하지만 모든 도구·전투 상태를 전수 재현하는 모델은 아니다. 확률적인 부가 효과와 모든 특수 변화기의 효과까지 추정하지 않는다. 탈·아이스페이스의 미입력 차단 상태 등 기존에 지원하지 않는 관측은 계속 안내하며, 기합의띠 발동 후 HP 1인 상대는 내구 추정에서 제외한다. 레드카드·탈출버튼으로 대면이 끝나면 새 관측으로 진행한다.
