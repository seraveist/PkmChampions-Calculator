# 역계산 결과 UI 후속 검토

사용자가 확정한 계산기 테마와 간결한 정보 위계를 역계산 결과에도 적용했다.

- 후보 머리글: 번호 → 성격·도구·특성 → 추정 노력치 범위. 예시는 `예시 H32 · A32 · D2`처럼 짧게 표시한다. 실제 일치 후보의 배분 계산과 H32 우선순위는 유지한다.
- ‘완성 66’, 역할 분류·속도 해설, ‘랭크 변화 없음’과 변하지 않은 도구 목록을 제거했다.
- 다음 턴 상태는 실제 포켓몬 이름·HP와 체력 바로 표시한다. 0이 아닌 최종 랭크, 소모된 도구, HP·타입 변화 등 발생한 항목만 태그로 표시한다. 랭크 발동 설명과 최종 랭크의 중복도 합쳤다.
- 기술은 일정한 행으로 정렬하고 타입 배지·분류, 선후공, 피해 %·실수치, KO 여부를 나눴다. 확정 KO는 공격색, 난수 KO는 본문색을 사용한다. 후보별 결과 차이는 그대로 구별한다.
- 타입 배지는 계산된 기술 타입을 사용한다. 웨더볼은 비에서 물 배지가 표시된다.
- 카드 머리글만 펼침 버튼이다. 피해량을 클릭하거나 선택해도 접히지 않으며 Enter 조작 후 포커스가 유지된다. 후보 설명·노력치·상세 영역 참조를 연결했다.

## 구조와 검증

결과 마크업은 `04-43-revcalc-render.js`, 배치는 `pages/reverse.css`에서 관리한다. 배지·글자 크기·테마색·포커스·체력 바는 공통 부품을 사용한다. 도감의 지연 로딩 함수에 의존하지 않는다. 사용하지 않는 이전 결과 CSS와 표현 함수를 제거했다. 중복 CSS 소유자와 가려진 반응형 규칙은 0이다.

- HTML·CSS 구조, CSS 우선순위, JS 참조 및 공개 빌드 검사 통과.
- 역계산 기존 골든 검사, 공방 33개 검사, 역계산 정책 9개 검사 통과.
- 실제 브라우저에서 도구 없음·미관측 입력, Worker 분석·재계산, 1440/375/320px 결과·예시 잘림, 카드 접기·펼치기, 키보드 포커스, 관측 변경 시 무효화 확인.
- 라이트·다크의 axe moderate/serious/critical 위반 및 애플리케이션 실행 예외 0.

스크린샷은 로컬 `../ui-reverse-results/`, 최신 실행 결과는 `reverse-exchange-browser-verification.json`에 보관했다. 화면 검증은 Chromium 반응형 에뮬레이션 기준이다.
