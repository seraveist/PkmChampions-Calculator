결정력 숫자는 현재 조건의 공격 능력치 × 보정 위력 × 자속·공격 보정 지수다. 방어 실수치와 타입 상성 배율을 곱한 실제 피해량은 결과 카드에서 확인한다. 반동·흡수는 기술의 성질만 표시하고, 총 피해에 단순 비례한 수치를 실제 회복량처럼 표시하던 부분은 제거했다.

## 계산 범위와 가정

- **1타는 기술 1회 사용**이다. 명중률, 행동불능, 상대 행동을 합한 승률이 아니다. 트리플악셀은 선택한 횟수가 적중하는 조건이며 자동은 3회 적중이다.
- 여러 번 사용하는 계산은 입력한 공격 조건을 반복하며 상대 HP, 열매 소비·회복, 탁쳐서떨구기의 도구 제거를 갱신한다. 기술 사용을 넘어서는 랭크·특성·날씨·필드의 연쇄 변화, 턴 수 경과와 도구 재획득은 진행하지 않는다.
- 선후공 자동은 같은 우선도를 가정해 실효 스피드와 트릭룸으로 판단한다. 우선도 차이는 직접 선공/후공을 지정한다. 동속은 조건 지정 안내를 표시한다.
- 집단구타는 사용자와 선택한 참여 가능 동료를 계산한다. 같은 ID 중복 참여는 제외하고 싱글 최대 3마리·더블 최대 4마리로 제한한다. 동료의 기절·상태이상 여부는 참여자 선택으로 지정한다.
- 폴터가이스트의 도구 없음과 아이언롤러의 필드 없음은 실패 이유를 표시한다. 도구·필드를 입력하거나 위력을 직접 지정해 가정 조건을 계산할 수 있다.
- 결과의 ‘회복 제외 HP’는 표시 피해를 현재 HP에서 뺀 참고값이다. 회복을 반영한 KO 판정과 구분한다.
- 다른 아군의 플라워기프트·강철정신 중첩 등 기존에 명시한 추가 아군 입력 한계는 남아 있다. 부수 효과를 통한 모든 접촉·상태·도구 변화의 조합을 완전 재현한다는 의미는 아니다.

## 검증과 진단 정정

- 전체 `npm test` 통과. 데이터·빌드·구조·피해·정책·역계산·상태 검사를 포함하며, 현재 수록 데이터가 없는 기존 검사 17개는 제외 표시를 유지했다.
- 새 계산기 재현 검사 28개, 기존 결정력 정책 검사 77개 통과.
- 배포 형태의 실제 브라우저 검사 85개 통과. 320px 조건 입력·회복 설명, 명암 대비·접근성, 실행 오류 없음 확인.
- 제한된 실행 환경에서 브라우저 연결 및 외부 리소스 접근 오류가 발생해, 네트워크 접근이 가능한 숨김 브라우저 환경에서 최종 검사했다. 동일한 검사에서 리소스 오류도 해소되었다.
- `git diff --check` 통과. 단독 실행 HTML과 배포용 빌드 생성 완료.

새 재현 검사는 `scripts/calculator-completion-golden.mjs`에서 실행한다. 단순 구현 복사 검사와 구분하여 고정 정답, 정수 HP 전 구간, 독립 난수 경계, 분포·입력 불변 조건, 실제 UI 동작을 함께 확인했다. 위협 반응의 일부 조합과 일반 공격 도구·속임수주사위 규칙은 검증용 조건이며 현재 포켓몬의 합법적인 선택 조합이라는 주장이 아니다.

앞선 분석에서 **구애머리띠를 실제 선택 가능한 오류 사례로 제시한 부분은 철회**한다. 현재 149개 도구에 구애머리띠와 속임수주사위가 없다. 수록 데이터의 존재를 확인하지 않고 ID만 입력한 진단이므로, 바디프레스+구애머리띠가 정상적으로 선택된 재현 사례로 볼 수 없다. 해당 일반 규칙은 별도 테스트용 도구를 만들어 검증했으며 도구 선택 목록에 미수록 아이템을 추가하지 않았다.

[특성·도구 분류표](power-mechanics-audit.md)는 현재 수록 특성 316개·도구 149개의 정책과 원본 이벤트 목록이다. 이번에 추가한 차단·회복·타격 중 변화·위협 반응도 분류에 연결했다. **ID 전수 분류는 모든 기술×특성×도구 조합의 정확성 인증이 아니다.**

기본 공식 대조 출처는 저장소의 `data/moves.ts`, `data/abilities.ts`, Champions 변경 데이터 및 [Showdown 피해 계산 구현](https://github.com/smogon/damage-calc/blob/master/calc/src/mechanics/gen789.ts), [최종 피해 함수](https://github.com/smogon/damage-calc/blob/master/calc/src/mechanics/util.ts)다.

작업 사본과 단독 실행 HTML에 반영했으며 커밋·원격 반영·배포는 하지 않았다.
