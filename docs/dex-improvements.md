# 도감 개선

2026-09-13. 도감 검토에서 확인한 데이터 표시·설명·계산기 적용 문제와 학습 기술 분류 필터를 반영했다.

## 사용 변화

- 포켓몬 상세와 팝업의 학습 기술에서 **전체·물리·특수·변화**를 선택할 수 있다. 기존 타입 필터와 함께 적용하며 표시 개수를 안내한다. 결과가 없어도 두 필터를 유지하고 빈 결과를 명시한다.
- 상세 화면과 팝업은 학습 기술 필터를 따로 보관한다. 다른 폼의 팝업을 열고 닫아도 원래 화면의 필터는 유지된다. 새 포켓몬의 상세 화면을 열면 전체 기술로 시작한다.
- 새 팝업은 이전 팝업의 스크롤 위치를 이어받지 않고 기본 정보부터 표시한다.
- 필터 변경 후 선택 버튼에 키보드 포커스를 유지하고 선택 상태를 보조 기술에 제공한다.
- 기술·특성 목록은 기본적으로 현재 수록 포켓몬과 연결된 항목을 표시한다. ‘전체 참고’를 선택하면 다른 참고 항목도 검색할 수 있다. 발버둥은 공통 기술로 기본 목록에 유지한다. 이 구분은 수록 데이터 기준이며 실시간 합법성 판정이 아니다.
- **거다이맥스 기술 33개는 현재 전체 데이터 출력에서 제외**한다. 도감과 계산기 기술 목록에 나타나지 않으며, 향후 다이맥스 지원을 위해 원본 파일은 보존한다. 빌드와 데이터 검증, 한국어 동기화 대상 필터가 모두 Gmax 태그를 제외한다.

## 데이터와 설명

현재 출력은 포켓몬 350개(폼 포함), 기술 536개, 특성 317개, 도구 167개다. 모든 출력 기술의 PP는 챔피언스 수정사항까지 병합한 원본과 일치한다. 기술 목록과 상세에서 PP를 확인할 수 있다.

기술의 위력 표시는 목록·상세·학습 목록 안내가 같은 함수를 사용한다. 가변 위력·고정 피해·일격기·변화기를 구분하며 내던지기·집단구타·변덕레이저도 표시한다. 조건 설명은 계산기와 동일한 메커니즘 키를 사용한다. 솔라빔의 날씨 없음, 필드 기술의 접지, 탁쳐서떨구기의 메가스톤 제외 등 확인된 조건 누락을 정리했다.

특성의 일반 평가값과 ‘필수급’ 문구는 제거했다. 기술은 내부 플래그 대신 접촉·소리·펀치·베기 등 읽기 쉬운 특징을 표시한다. 방어 타입 상성에는 특성·도구를 제외한 타입표임을 명시한다. 상세·팝업의 글자와 적용 버튼은 두 테마에서 대비를 보완했다.

## 계산기 적용

계산기 내부 선택과 도감 적용이 동일한 기술 슬롯 변경 함수를 사용한다. 기술을 적용하는 슬롯의 수동 위력·타입·급소·연속기 적중 횟수를 초기화한다. 같은 포켓몬에서 다른 슬롯의 설정이나 노력치·성격·필드는 유지한다. 부모 포켓몬을 함께 가져오는 경로도 변경 후 원하는 슬롯에 기술을 적용한다.

## 검증

전체 `npm test` 결과 **1,356 PASS / 0 FAIL / 기존 16 SKIP**. 마지막 팝업 스크롤 조정 후 도감 행동 검사·공개 빌드 준비 검사·실제 브라우저 검사를 다시 통과했다. 최종 도감 브라우저 검사는 **33 PASS / 0 FAIL**이다.

- `npm run dex:smoke`: 기존 데이터·구조 검증과 새 행동 검사 17개. PP의 원본 일치, 거다이맥스 제외, 조건 설명, 세 계산기 적용 경로, 슬롯 외 상태 보존, 필터 조합·빈 결과·독립 상태·참고 범위를 검사한다.
- `npm run dex:browser`: 실제 브라우저에서 필터·키보드·폼 팝업·계산기 적용·목록 범위·탭 복귀·초기화를 확인한다. 1440/375/320px에서 가로 넘침과 화면 자동 축소 없이 표시된다.
- 포켓몬 상세의 두 테마, 어두운 기술 팝업, PP가 포함된 모바일 기술 목록에서 접근성 검사상 critical/serious/moderate 위반이 없다.
- 브라우저 화면 확인 결과: [dex-browser-verification.json](dex-browser-verification.json).

수정 전 문제의 기록은 [도감 검토](dex-menu-review.md)와 `dex-menu-review-probes.json`에 남겼다. `scripts/dex-menu-review.mjs`는 수정 전 버전의 문제 재현용이며, 현재 버전의 검증은 위 명령을 사용한다.
