# 세부조정 개선

2026-09-13. `d05592c` 이후 세부조정 재분석에서 확인한 배치·조건 유실, 스피드 목표 표시, HP 조정 효과, 기준 배분 비교를 개선했다.

## 사용 흐름

1. 포켓몬을 선택하거나 파티·계산기에서 배치를 불러온다. 처음 선택하거나 불러온 배분·성격이 비교 기준이 된다.
2. 양쪽 도구·특성·상태·랭크·순풍과 공통 날씨·필드를 설정한다.
3. 상대 최속·준속·무보정·입력 배치의 속도와 내 최소 S 투자량을 비교한다. 상대 보정 후 속도 실수치를 직접 입력할 수도 있다.
4. 남은 포인트로 적용할 수 있는 목표는 바로 적용한다. 부족한 목표는 필요한 재배분량을 확인하고 다른 능력치를 직접 조정한다.
5. HP 기준점의 조정 후 HP와 실제 회복·소모량을 확인한다. 기준 배분과 현재의 실수치·내구 지표·속도 차이를 비교하고 계산기로 보낸다.

H32를 강제하지 않는다. 사용자가 정한 스피드·HP 조건에 맞춰 자유롭게 배분한다.

## 배치와 조건 보존

양쪽 모두 완전한 계산기 배치를 보관한다. 계산기에서 내 S만 조정해 되돌아와도 상대의 노력치·성격·도구·기술·HP를 초기화하지 않는다. 날씨·필드와 기존 계산기 조건도 보존한다. 계산기로 보낼 때 필드 화면까지 동기화한다.

비·쓱쓱 침바루는 세부조정과 계산기 모두 S0에서 210, S1에서 212로 계산된다. 공격측·방어측 양방향 왕복을 검증했다.

새 포켓몬을 고르거나 파티 배치를 불러오면 이전 포켓몬의 마비·순풍·랭크 등의 상태를 이어받지 않는다. 불러온 현재 상태는 입력과 요약에 표시하며 ‘랭크·상태 초기화’로 정리할 수 있다. 공통 날씨·필드는 별도로 유지한다.

## 스피드 목표

양쪽 모두 공통 스피드 엔진을 사용한다. 상대 비·쓱쓱 준속 침바루는 274로 표시되며, 랭크·도구·마비·순풍과 상대 특성에 의한 억제도 같은 계산 경로를 사용한다.

추월 가능 여부를 다음처럼 구분한다.

- 현재 달성 / 적용 가능
- 재배분 필요: 최소 S, 현재 S 배정 가능량, 다른 능력치에서 필요한 포인트
- S32 내 달성 불가

한카리아스 H32/A32에서 최속 침바루를 추월하려면 ‘최소 S29 / 배정 가능 2 / 다른 능력치에서 27pt 필요’로 표시한다. 적용 버튼은 부족할 때 비활성화되며, 내부 적용 함수도 총합 66을 초과하는 변경을 거부한다. 다른 능력치에서 자동으로 차감하지 않는다.

차이 0은 동속 이상이다. 직접 입력한 상대 실수치에도 같은 차이를 적용한다. 종족값은 포켓몬 데이터로 표시하고, 직접 입력하는 보정 후 실수치와 구분한다.

최속·준속·무보정은 S와 성격의 비교 배치이며 다른 축은 무투자로 계산한다. ‘입력 배치’는 상대의 기존 전체 배분을 사용한다. 스피드 비교는 기술 우선도나 트릭룸의 실제 행동 순서 판정이 아니다.

## HP 기준점

현재 HP, 이전·다음 기준점의 HP와 H 투자량, 필요한 포인트, 회복·소모량을 함께 표시한다. 총합이 부족한 기준점도 부족량을 표시하며 적용을 막는다.

- 먹다남은음식: HP159의 회복 9와 HP160의 회복 10처럼 실제 내림 차이를 표시한다.
- 자뭉열매: HP156에서 발동선 78, 회복 39; HP160에서 발동선 80, 회복 40을 표시한다.
- 선택한 회복 도구와 생명의구슬을 관련 항목으로 표시한다.
- 매직가드, 접지 여부, 타입 등을 반영해 해당하지 않는 간접 피해 기준을 제외한다.
- 대타출동·고정 비율 소모 등의 일반 참고 조건을 구분한다.

HP 기준점은 최적 배분의 단정이 아니다. 표시한 반복 횟수는 해당 단일 효과만 최대 HP부터 반복했을 때의 값이며, 다른 공격·회복·복합 효과를 포함하지 않는다.

## 기준 배분 비교

기준과 현재의 여섯 실수치, 물리·특수 내구 지표, 보정 후 속도, 남은 포인트를 비교한다. 현재 도구·특성·필드를 양쪽에 동일하게 적용해 배분과 성격의 차이를 보여 준다.

‘현재를 기준으로’는 비교 기준을 바꾼다. ‘기준 배분 복원’은 포인트·성격만 되돌리고 현재 도구·필드 등은 유지한다. 내구 지표는 HP×방어·특방 기반이며 특정 기술의 생존 판정이나 랭크·특성·도구의 직접 피해 보정을 포함하지 않는다.

특정 상대 KO·생존 목표를 동시에 만족시키는 자동 배분 탐색은 이번 변경 범위에 추가하지 않았다.
