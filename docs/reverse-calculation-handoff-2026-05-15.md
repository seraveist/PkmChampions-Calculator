# Reverse Calculation Handoff 2026-05-15

이 문서는 `내구 역계산` 탭만 따로 이어받기 위한 상세 문서다.

## Goal

포켓몬 챔피언스 룰의 포인트 제약을 이용해, 한 턴의 데미지 관측값으로 상대 포켓몬의 성격, 도구, 노력치 범위를 좁힌다.

현재 목표는 단일 정답을 강제로 만드는 것이 아니라 다음을 정확히 구분하는 것이다.

- 관측값으로 논리적으로 가능한 후보
- 실전적으로 그럴듯한 후보
- 역할 기준으로 66포인트를 채운 대표 형태

## Input Semantics

현재 입력 의미는 다음과 같다.

- 상대 잔여 HP: 퍼센트
  - 예: 상대가 33% 남았다면 `33`
- 내 남은 HP: 실제 HP 정수
  - 예: 내 최대 HP가 167이고 135 데미지를 받았다면 `32`

이 둘을 혼동하면 후보가 0개가 될 수 있다.

## Core Flow

1. 내 공격이 상대에게 준 데미지로 상대 내구 후보를 만든다.
2. 상대 공격이 내게 준 데미지로 상대 화력 후보를 만든다.
3. 두 후보를 성격, 도구, 포인트 총합 기준으로 교차 검증한다.
4. 선후공 정보가 있으면 스피드/스카프 후보를 제한한다.
5. 남은 후보를 관측 범위로 그룹화한다.
6. 성격과 역할 우선순위로 66포인트 완성 추정을 붙인다.

## Candidate Generation

주요 함수 위치: `src/js/04-views.js`

- `rcBuildDefenseMatches()`
  - 내 공격 관측값으로 상대의 `H + B` 또는 `H + D` 후보를 만든다.
- `rcBuildOffenseMatches()`
  - 상대 공격 관측값으로 상대의 `A` 또는 `C`와 도구 후보를 만든다.
- `rcCombineReverseCandidates()`
  - 방어 후보와 화력 후보를 합쳐 66포인트 룰과 스피드 룰을 적용한다.
- `rcRoleCompletionInfo()`
  - 관측 범위 안에서 역할 우선순위에 따라 66포인트 완성 추정을 만든다.
- `rcRolePresetScore()`
  - 성격/도구/스피드/역할의 실전성을 점수화한다.

## Nature Filtering

상대가 쓴 기술의 분류를 기준으로 1차 성격 후보를 제한한다.

물리 기술:

- 고집
- 명랑
- 장난꾸러기
- 대담
- 신중
- 차분

특수 기술:

- 조심
- 겁쟁이
- 장난꾸러기
- 대담
- 신중
- 차분

막이 성격을 양쪽에 넣는 이유는 첫 턴의 공격 기술만으로 상대가 공격형인지 막이형인지 알 수 없기 때문이다.

## Magic Number Handling

매직넘버는 종족값에 따라 계산한다.

비 HP 스탯의 원시값은 대략 `base + 20 + point` 구조이므로, 성격 보정 전 10의 배수에 도달하는 포인트를 매직넘버로 본다.

관련 함수:

- `rcMagicEvsForStat(oppP, stat)`
- `rcSecondMagicEv(oppP, stat)`

속도 상승 성격이나 공격 상승 성격의 실전성 판단에서 이 값이 사용된다.

## Role Completion

결과 화면의 완성 추정은 확정값이 아니다. 관측 가능한 EV 범위 안에서 66포인트를 어떤 식으로 채울지 보여주는 대표 형태다.

예시:

```text
관측 범위: H1~14 / C14~17 / S0~32
완성 추정: 딜탱형 · H14 / B32 / C17 / S3
```

이 뜻은 실제로 B32가 관측되었다는 것이 아니라, C와 H가 관측 범위로 제한된 상태에서 딜탱형으로 66포인트를 채우면 B 쪽에 남는 포인트가 들어간다는 의미다.

## Regression Test

새 테스트 스크립트:

```powershell
npm.cmd run reverse:golden
```

전체 테스트:

```powershell
npm.cmd test
```

`reverse:golden`은 다음을 검증한다.

- 내 HP 입력이 퍼센트가 아니라 실제 남은 HP인지
- 역계산 후보가 0개로 잘못 떨어지지 않는지
- 스테이지 1 후보가 오래된 slice 필터로 잘리지 않는지
- HP 우선 정책이 관측 범위 표시에서 깨지지 않는지
- 역할 완성 추정이 결과 그룹에 붙는지

## Known Tradeoffs

- 현재는 첫 턴 관측 기반이다.
- 상대 도구를 사용자가 잠그는 기능은 의도적으로 넣지 않았다.
- 도구 후보는 결과를 좁히기 위한 필터가 아니라 가능한 후보군이다.
- 한 턴 정보만으로는 난수와 도구/성격 후보가 남을 수밖에 없다.
- 따라서 결과는 "확정"보다 "상위 후보와 대표 형태"로 읽어야 한다.

## 2026-05-15 Form Reverse v1 Notes

이 시점의 역계산 메뉴는 `형태 역계산` 1차 완성본으로 본다. 현재 철학은 "한 턴으로 상대 형태를 확정한다"가 아니라, "관측값으로 말이 되는 후보를 줄이고 다음 행동을 판단할 수 있는 데미지 정보를 붙인다"에 가깝다.

### UI Flow

1. 내 포켓몬, 성격, 포인트, 기술폭 4개를 입력한다.
2. 상대 포켓몬, 관측된 상대 사용 기술, 상대 잔여 HP, 내 남은 HP, 선후공 정보를 입력한다.
3. 분석 버튼을 누르면 상위 5개 형태 후보를 축소 카드로 보여준다.
4. 카드를 클릭하면 개별적으로 확장되고, 다시 클릭하면 접힌다.
5. 확장 카드 안에서는 다음 3개 영역을 같은 행에 표시한다.
   - 상대 예상 정보
   - 상대 다음 예상 기술
   - 내 다음 기술 대미지

### Move Input Policy

- 기술 입력은 모두 한국어 기술명 기준 검색형 콤보박스다.
- 내 기술폭 4개는 기술명만 표시한다.
- 관측 데이터의 `내 사용 기술`은 입력한 기술폭 4개에서만 고른다.
- 상대 사용 기술과 상대 예상 기술은 전체 기술 목록에서 검색한다.
- 사용자가 직접 타이핑한 한국어 기술명은 `toId()`가 비어도 한국어 이름으로 다시 찾아 실제 move id에 연결한다.
- 필터는 입력값으로 시작하는 기술을 먼저 보여주고, 없으면 포함 검색으로 fallback한다.

### Ability Policy

- 상대 특성 입력 UI는 제거했다.
- 역계산 과정에서는 데미지에 영향을 주는 특성 후보를 내부적으로 탐색한다.
- 후보가 특정 특성 때문에 성립하면 결과 카드에 특성 배지를 표시한다.
- 여러 특성이 동시에 가능하면 가능한 특성을 모두 배지로 표시한다.
- 특성이 결과에 영향을 주지 않거나 특정되지 않으면 표시하지 않는다.

현재 회귀 검증에 포함된 대표 케이스:

- 메가캥카가 냉동펀치로 마릴리를 공격하고, 마릴리가 치근거리기로 반격하는 상황.
- 마릴리 `hugepower`가 화력 후보에 포함되어야 한다.
- 메가캥카의 `parentalbond` 데미지 경로가 누락되면 후보가 잘못 정렬될 수 있으므로 회귀 테스트에서 방지한다.

### Item and Scarf Policy

- 상대 도구가 미관측이면 후보군은 `없음`, 자속 타입 강화 도구, 구애스카프를 중심으로 본다.
- 구애스카프는 선후공 조건을 만족시키는 강한 후보지만, 비스카프도 66포인트 안에서 성립하면 스카프 보너스를 낮춘다.
- 데미지 상승 도구도 기본적으로 감점하여, 관측값만으로 불필요하게 상위에 고정되지 않도록 했다.

### Result Card Policy

- 결과는 최대 5개만 표시한다.
- 축소 카드에는 상대 형태 텍스트와 핵심 배지만 보여준다.
- 확장 카드에는 다음 영역을 3열로 보여준다.
  - `상대 예상 정보`: 관측 범위, 역할형, 도구, 성격/특성 배지 등
  - `상대 다음 예상 기술`: 다음 피격 데미지 계산용 기술 선택과 랭크 입력
  - `내 다음 기술 대미지`: 내 기술폭 4개의 다음 데미지 퍼센트와 KO 상태
- 내 다음 기술 데미지는 실수치 HP 표기를 제거하고 퍼센트와 KO 상태만 표시한다.
- KO 상태는 현재 상대 잔여 HP 기준으로 `KO 불가`, `KO 난수`, `KO 확정`으로 나눈다.

### Partial Observation Badges

관측 정보가 일부 비어 있으면 결과를 막지 않고 배지로 알려준다.

- `공격축 미확인`: 상대가 변화기를 쓰거나 내 피해 관측이 없는 경우
- `속도 미확인`: 선후공 정보가 없거나 선공기 등으로 일반 스피드 비교가 어려운 경우
- `내구 미확인`: 내가 공격하지 않아 상대 내구 관측이 없는 경우

이 배지들은 후보가 틀렸다는 뜻이 아니라, 해당 축의 증거가 부족하다는 뜻이다.
