# 역계산 입력·결과 정리 — 2026-09-14

## 화면

- 입력 값과 선택 값은 공통 `--weight-control:650`을 사용한다. 능력치 입력에 있던 별도 굵기 지정은 제거했다. 안내 라벨과 설명은 기존 위계를 유지한다.
- 내 시작 HP는 `시작 HP [212] / 212 [건강]`, 상대는 `시작 HP [100] % [건강]`처럼 한 행에 표시한다. 기존 HP 제한과 상태 선택 동작은 유지한다.
- 결과 상단의 H32 우선, 후보 수, 대표 수, 그룹 수를 제거했다. 내부 검색·정렬에 필요한 수치는 유지한다.
- 선공하는 참가자의 기술에만 초록색 굵은 `선공`을 표시한다. 상대편 카드에 같은 판정을 반복하지 않는다. 동속·불확정 결과는 확정 선공으로 표시하지 않는다.
- 결과 카드의 피해 퍼센트는 26px에서 22px로 줄였다. 여백도 줄이고, 이름과 HP·막대를 가로로 배치했다. 변경된 랭크나 도구 효과는 별도 태그로 유지한다.

## 상대 검색 성격

검색은 고집·명랑·장난꾸러기·신중·조심·겁쟁이·대담·차분·천진난만·용감의 10개 성격으로 제한한다. `RC_NATURE_IDS` 한 곳에서 본문과 워커의 검색 범위를 제어한다. 직접 편집하는 포켓몬의 성격 목록은 25개를 유지한다.

성격 제한에 따라 후보 수, 대표 형태, 가능한 노력치·피해 범위는 달라질 수 있다. 이전 테스트에서 전체 25개 성격을 전제로 고정했던 H32·공격 32 기대값은, 허용된 성격 중 실제 관측을 만족하는 최댓값을 검증하도록 변경했다. H32가 가능한 경우 우선하는 정책과 66포인트 제한은 유지한다.

## 검증

- `reverse-policy-golden.mjs`: 허용된 10개 성격과 수동 선택 25개를 확인한다.
- `reverse-exchange-golden.mjs`: 허용 성격만 후보로 포함되는지, 양쪽의 선공·동속 표시가 중복되거나 뒤바뀌지 않는지 검사한다.
- `reverse-performance-check.mjs`: 기존 `9bac1b3`에도 같은 10개 성격을 적용한 뒤 모든 후보·경로·그룹·예측 결과를 대조했다. 3개 케이스의 전체 결과가 일치한다. 기록은 `docs/reverse-ten-nature-performance.json`에 있다.
- 메가캥카·마릴리 대면에서 내 기술에만 선공을 표시하는지 실제 브라우저로 확인했다. 시작 HP·상태와 양쪽 결과의 이름·HP 영역을 320/375/1440px에서 확인했다.
- 공통 입력 굵기, 라벨 참조, 키보드 조작, 가로 넘침, 밝은/어두운 테마의 접근성을 기존 전체 메뉴 검사로 확인했다.
