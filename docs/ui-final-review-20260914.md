# UI 최종 검토 — 2026-09-14

검토 기준은 main의 9bac1b3 이후 요청된 전체 UI 개선이다. 화면과 동작은 현재 승인된 구성을 유지한다. 이전 단계의 기록인 ui-polish-20260914.md와 reverse-compact-review.md 이후 변경도 이 문서에 포함한다.

## 최종 반영 내용

- 공통 본문·라벨·입력 글꼴과 대비를 조정하고 입력 값의 굵기를 통일했다. 상태 선택은 중앙 정렬된 공통 팝업을 사용한다.
- 역계산은 시작 HP·상태를 한 행에 배치하고, 상대 기술배치 4칸에서 마지막으로 선택한 기술을 관측 상대 공격에 반영한다. 트릭룸도 공통 선택 UI를 사용한다.
- 결과는 내 포켓몬과 상대 프레임을 구분하고 이름·HP를 가로로 배치한다. 선공 표시는 실제 선공하는 쪽에만 초록색으로 표시하며 불필요한 후보·그룹 설명을 제거했다.
- 상대 검색은 요청된 10개 성격으로 제한한다. HP 전용 계산과 불가능한 관측 경로의 사전 확인으로 중복 계산을 줄였다. 성격 제한은 검색 정책 변경이며, 최적화 정확성 비교는 양쪽 모두 같은 10개 성격을 적용한 결과다. 기존 3개 케이스의 전체 결과 일치 기록은 reverse-ten-nature-performance.json에 있다.
- 세부조정은 차이 입력의 + 표시와 적용·현재 달성·도달 불가 표시 크기를 통일했다. 기준 배분 비교, 적용 알림, 내 특성·도구 설명은 제거했다.
- HP 기준점은 같은 목표 HP를 한 카드로 묶고 추가 투자·노력치 절약·참고 기준점으로 구분한다. 장착 도구와 사용 기술에 관련된 목표를 우선하며 현재 충족 조건과 필요한 포인트를 간결하게 표시한다.
- 도감 상세 상단은 하나의 프레임 안에서 종족값과 특성·폼·상성을 구분한다. 작은 화면에서는 세로로 전환하며 학습 기술 목록은 기존 기능을 유지한다.

## HTML·CSS 검토

- 5개 메뉴, 상세 화면, 공통 선택 팝업, 설정·파티 대화상자의 계층과 참조를 확인했다. 검증 대상에서 중복 ID, 끊긴 라벨·ARIA 참조, 중첩된 상호작용 요소, type이 없는 버튼, 의도하지 않은 페이지 가로 넘침은 없었다.
- 공통 제어 요소·프레임·상태·참가자·선택 목록은 components가 소유하고, 페이지 파일은 배치와 해당 메뉴 표현을 담당한다. 페이지 간 CSS 소유권 침범은 없다.
- 18개 스타일 파일의 무조건부 중복 속성 소유 0건, 뒤의 기본 규칙에 가려진 반응형 선언 0건. !important는 hidden 속성 보존 규칙 1개뿐이다. 테마는 공통 색상 토큰을 사용한다.
- 삭제된 관측 입력 상태 문구의 갱신 인수를 정리했다. 잠금 상태 및 분석 결과 상태 표시는 유지한다.
- 상태 팝업의 Escape 검증은 브라우저가 비동기로 발생시키는 toggle 이벤트가 끝난 뒤 판정하도록 보완했다. 선택 값 유지와 원래 버튼으로의 포커스 복귀를 함께 확인한다.

## 검증 결과

- 전체 npm test 성공: 구문·HTML/CSS/JS 구조, 데이터·계산 정책·역계산·메뉴 상태 및 공개 배포 산출물 검사. PASS 1,018건이며 현 챔피언스 데이터에 없는 기술·도구·포켓몬 관련 16건은 기존 정책에 따라 제외된다.
- 전체 메뉴 브라우저 검사: 5개 메뉴 × 2개 테마 × 9개 너비(320~1440px), 선택 팝업·설정·초기 메뉴 이동·공통 입력 크기 검사 성공.
- 계산기·역계산·세부조정·도감·상성표·파티 개별 브라우저 검사 성공. 실제 클릭·키보드 조작, 상태 변경, 접기·펼치기, 테이블 스크롤과 도감 상세·폼 전환을 포함한다.
- 단일 HTML, 일반 공개 빌드, 광고 없는 Pages 빌드의 전체 브라우저 검사가 모두 성공했다. 검사한 화면에서 axe의 critical/serious/moderate 위반과 런타임 예외는 없었다.
- 마지막 문구 정리 후 구문·HTML/JS 구조·공개 배포 준비 검사와 일반 공개 빌드의 전체 브라우저 검사를 재실행했다.
- 배포 HTML을 재생성했고, 로컬 미리보기는 Pages 빌드와 기존 계산기 샘플로 복원했다. 공백 오류 검사도 통과했다.

원시 화면 검사 결과는 기존 *browser-verification.json과 ui-remodel-final-browser.json에 기록한다. 캡처와 로그는 저장소 바깥의 ../ui-release-*-20260914/ 및 ../ui-release-*.log에 보관한다. 검증 브라우저는 로컬 Chromium이며 이 기록이 다른 브라우저 엔진의 실행 검증을 의미하지는 않는다.
