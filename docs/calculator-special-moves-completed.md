# 예외 기술 3항목 보완 완료

2026-09-08. [완료 전 재검토](calculator-readiness-review.md)에서 확인한 세 항목을 반영했다. 해당 재검토의 보류 판단은 이번 보완으로 해소되었으며, 다음 메뉴 개선으로 전환할 수 있다.

## 변덕레이저

- 기본값은 확률 반영: 일반 위력 80(70%)과 강화 위력 160(30%)을 정확한 가중 분포로 합산한다. 반복 사용 때마다 강화 여부와 피해 난수를 독립적으로 계산하며 회복도 함께 반영한다.
- 일반 고정·강화 고정도 선택할 수 있다. 고정 모드에서는 조건부 KO 확률이며 강화 발생 확률을 곱하지 않았음을 결과 카드에 명시한다. 모바일 요약에도 선택한 모드가 표시된다.
- 과미드라 → 잠만보 현재 HP 100/최대 235, 무투자·무보정·도구 없음: 자동 피해 49~115, 난수 1타 24.4%. 일반 고정은 49~58, 강화 고정은 97~115다.

## 카운터·미러코트·메탈버스트·앙갚음

- 이번 턴 마지막으로 받은 HP 피해와 물리·특수 분류를 입력한다. 연속기는 마지막 1회의 HP 피해만 사용한다.
- 카운터·미러코트는 해당 분류 피해의 2배, 메탈버스트·앙갚음은 1.5배를 내림한 고정 피해로 계산한다. 피격은 있었지만 HP 피해가 0인 경우는 원본 규칙에 따라 1이다.
- 예: 받은 피해 51 → 카운터/미러코트 102, 메탈버스트/앙갚음 76. 공격·방어 능력치나 일반 상성 배율을 곱하지 않는다. 무효는 합의된 결정력 정책대로 별도 안내한다.
- 미입력 및 카운터·미러코트의 잘못된 피격 분류는 이유를 표시한다. 일반 위력 편집을 비활성화하고 기존 수동 위력 상태가 남아 있어도 해당 고정 피해 규칙을 우회하지 못하게 했다.
- 반복 KO 타수에는 매회 같은 피해를 받고 생존했다는 조건이 필요함을 표시한다. 상대 턴을 자동 재현하는 방식은 아니다.

## 내던지기·토해내기

- 내던지기는 보유 도구의 위력을 자동 사용한다. 검은철구 130, 열매 10을 포함하며 빌드에서 누락되었던 열매의 기본 내던지기 위력도 보존한다.
- 도구 없음, 사용 불가 특성, 해당 포켓몬의 메가스톤 등은 구체적인 사용 불가 메시지를 표시한다. 부자유친의 추가 타격 제외 플래그도 반영한다.
- 던진 회복열매의 회복을 자체 HP 발동선과 무관하게 적용한다. 보유 반감열매의 피해 도중 소비 → 던진 열매의 회복 → 보유 HP 열매 발동선 순서이며, 볼주머니·숙성과 KO 후 회복 없음도 검사했다.
- 도구의 상태·랭크 부가 효과는 합의된 동일 입력 조건 반복 범위에서 제외함을 표시한다. 반복 타수는 매회 같은 도구를 다시 보유한 조건이다.
- 토해내기는 비축 0~3회를 입력한다. 0회는 사용 불가, 1/2/3회는 위력 100/200/300이다. 반복 타수는 매회 같은 횟수로 재비축한 조건으로 명시한다.
- 두 기술 모두 일반 위력 수동 입력으로 필요한 조건을 우회할 수 없다.

- 전체 자동 검사: **1,258개 통과, 실패 0개, 기존 건너뜀 17개**.

- 집중 브라우저 검사: **100개 통과**. 1440px·375px·320px에서 새 결과 카드의 경계·겹침·가로 넘침과 320px 입력 이벤트를 검사했다.
