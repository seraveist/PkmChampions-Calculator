# 대미지 계산기 UI 샘플

2026-09-13. 사용자가 요청한 첫 화면 개편 샘플. 주소: `/calculator-sample.html`.

## 반영 기준

- 현재 스마트 로토무 색상과 라이트·다크 테마를 공유한다.
- 노력치·랭크·실수치는 두 포켓몬 모두 항상 표시한다. 필드 설정은 기본적으로 접는다.
- 기술 선택, 피해 범위, KO 횟수·확률을 같은 행에 모은다.
- 기술 조건 팝업은 위력·타입·급소를 한 줄로 정렬한다.
- 난수·확정 판정은 피해 수치와 같은 크기로 표시하고, `18.4% 확률`은 판정 아래에 작게 분리한다. 판정 글자는 기술 선택칸·설정 버튼과 세로 중심을 맞추며, 확률은 판정의 정렬 높이에 포함하지 않는다. 확정 판정도 같은 중심선을 사용한다.
- 사용 안내 문단을 추가하지 않는다. 적용된 피해 보정·무효·회복 조건은 결과에 짧게 표시한다.
- 결과 태그는 `땅 무효`, `부유 무효`, `멀티스케일 ×0.5`, `먹다남은밥 회복`처럼 줄이고, 피해 산출 제외 등의 안내는 표시하지 않는다.
- 모바일에서는 포켓몬 카드를 세로로 배치한다. 결과 버튼 없이 아래로 스크롤해 피해 결과를 확인한다.
- 상태 선택값은 화살표 공간을 양쪽에 동일하게 확보해 중앙 정렬한다. 모바일 교대 버튼은 두 포켓몬 카드 사이의 가로 중앙에 배치한다.
- 필드 설정은 날씨·필드·배틀을 한 행에 배치하고 `등장 특성`, `리플렉터`, `빛의장막` 등 짧은 명칭을 사용한다.
- 기술 선택 화살표는 선택 영역 오른쪽에 크게 표시한다.
- 선택 목록은 한 행을 유지한다. 포켓몬 이름 열은 160px(480px 이하 140px)로 고정하고, 타입 배지 두 열은 각각 40px로 맞춘다. 종족값 6개·합계를 이어서 배치하며 좁은 화면에서는 포켓몬 목록 내부를 가로로 스크롤할 수 있다. 기술·도구·특성은 설명, 성격은 상승·하락 능력치를 이름 오른쪽에 표시한다. 긴 설명은 말줄임과 전체 내용 툴팁을 제공한다.
- 검색창 포커스는 둥근 외곽선 하나로 표시한다. 목록 내부만 스크롤하며, 키보드 초점은 행 내부의 테두리로 구분한다.
- 성격 목록은 이름·상승·하락을 같은 열로 맞춘다. 상승은 빨간색 `공격 ↑`, 하락은 파란색 `특공 ↓`처럼 표시하고 무보정 성격은 `보정 없음`으로 표시한다.
- 기술 목록의 보조 정보는 타입 배지·굵은 위력·분류·설명 순서로 열을 맞춘다. 기본 위력이 없는 기술은 `—`로 표시한다. 긴 설명은 한 줄 말줄임과 전체 내용 툴팁을 유지한다.
- 선택 행 높이는 48px(480px 이하 44px)로 통일한다. 목록 높이는 고정 머리글과 가로 스크롤바를 제외한 정수 개의 행에 맞추며, 스크롤이 멈추면 행 경계에 정렬한다. 키보드 이동은 고정 머리글 아래에 행 전체를 표시하고 검색·재열기는 양쪽 스크롤 위치를 초기화한다.
- 키보드 선택 후 원래 입력 버튼으로 초점을 돌려주고 2px 테두리로 표시한다. 마우스 선택 후에는 초점 테두리가 나타나지 않는다. 현재 선택값은 목록에서 구분한다.
- 제목·이름/수치·보조 정보의 글자 크기를 공통 변수로 관리한다. 모바일에서도 결과 태그는 11px을 유지한다.

## 실행

```sh
npm run build:pages
npm run sample:calculator
node scripts/serve-dist.mjs 4173
```

`http://127.0.0.1:4173/calculator-sample.html`에서 확인한다. 일반 빌드는 `dist`를 새로 만들므로, 샘플 생성은 일반 빌드 다음에 실행한다.

## 구현 범위

`samples/calculator/`가 독립적인 화면을 제공한다. 현재 데이터 7종, 공통 색상 토큰, 피해 엔진, 계산기 상태·등장 특성 처리를 기존 소스에서 가져온다. 피해 계산식을 복제하지 않는다.

포켓몬·특성·도구·성격 검색, 노력치 총합 66 제한, 랭크, 현재 HP, 상태이상, 공격·방어 교체, 필드, 기술별 급소·위력·조건 변경이 실제 계산에 연결된다. 첫 화면에는 한카리아스와 망나뇽의 예시 설정이 들어 있다. 종을 변경하면 해당 포켓몬의 설정과 기술을 초기화한다.

현재 메뉴를 대체하는 배포본은 아니다. 파티 저장·불러오기, 다른 메뉴에서 설정 가져오기, 모든 특성별 수동 발동 스위치의 화면 이전은 본편 통합 단계의 범위다. 기존 계산기와 다른 메뉴의 화면·로직은 이번 샘플 작업에서 변경하지 않았다.

## 공통 UI 계층

포켓몬의 문자 화살표와 기술의 SVG 화살표를 하나로 통합했다. 샘플의 UI 구조는 다음 책임으로 나눈다.

| 소스 | 책임 |
| --- | --- |
| `samples/calculator/ui.js` | 아이콘, 선택 버튼, 기본 선택칸, 숫자 입력, 라벨과 체크박스의 공통 마크업. 정적 HTML의 아이콘도 같은 정의로 생성. |
| `samples/calculator/ui.css` | 테마 연결, 글자 위계, 공통 버튼·입력·화살표·팝업·태그·막대 및 초점·호버·비활성 상태. |
| `samples/calculator/calculator.css` | 페이지·공격/방어 카드·결과·팝업 내부 배치와 반응형 구성. 크기 차이는 공통 요소의 변수로 지정. |
| `samples/calculator/calculator.js` | 계산 상태를 공통 UI에 전달하고 입력을 기존 엔진에 연결. 피해 계산식은 변경하지 않음. |
| `samples/calculator/index.html` | 페이지의 의미 구조와 정적 공통 요소. |

- 모든 선택 버튼은 `ui-select-trigger`의 내용 영역과 오른쪽 `ui-chevron`을 사용한다. 포켓몬·기술은 20px, 특성·도구·성격과 상태이상은 16px, 좁은 랭크 칸은 10px 변형이다. 선 모양·색·두께는 공통 정의를 따른다.
- 특성·도구·성격은 라벨 행의 오른쪽에 화살표를 두어 값 행의 폭을 확보한다. 320px에서도 기본 설정의 모래숨기·생명의구슬·멀티스케일이 생략되지 않는다.
- 필드·상태·랭크·기술 조건은 같은 기본 선택칸을 사용한다. 실제 `select`를 유지해 키보드와 모바일 기본 선택 기능을 보존한다. 장식 화살표는 클릭과 초점을 가로채지 않는다.
- 선택창의 행과 필터, 아이콘 버튼, 완료 버튼은 공통 버튼의 변형이다. 검색창에는 둥근 초점 표시 하나만 적용한다.
- 카드·팝업은 공통 표면, 결과 태그·타입 표시는 공통 태그, HP·피해 막대는 공통 막대를 사용한다.
- 네 결과 행은 부모 그리드의 열을 함께 사용한다. KO 문구 길이가 달라도 기술 선택칸의 폭과 화살표·판정·조건 버튼 위치가 일치한다. 기술명은 750, KO 판정과 피해 수치는 800, 물리·특수 및 위력은 500 굵기로 구분한다. KO 판정은 피해 수치와 같은 26/25px(PC/모바일), 확률은 판정 아래에 12px로 표시한다. 난수 판정은 본문색(라이트 테마 검은색), 확정 판정은 기존 빨간색을 사용한다. 피해·판정의 숫자는 일정한 자폭을 사용한다.

추가 검증은 `scripts/calculator-sample-components.mjs`, 기록은 `docs/calculator-sample-components-review.json`에 있다. 1440·768·375·320px의 화살표 위치와 이름 표시, 결과 행의 열 정렬과 보조 텍스트 굵기, 팝업을 포함한 29개 화살표의 공통 변수 변경 전파, 화살표 직접 클릭, 랭크 키보드 변경과 계산 연결을 확인한다. 기존 계산·반응형·접근성·키보드 검증도 함께 실행한다.

## 선택 행 정렬 점검

`scripts/calculator-sample-picker-alignment.mjs`는 선택창 5종의 모든 행을 1440·700·375·320px와 667×375 가로 화면에서 측정한다. 기록은 `docs/calculator-sample-picker-alignment-review.json`에 있다.

- 외로움 행을 위쪽으로 10px 잘라 호버했을 때, 내부 요소는 정렬되어 있어도 보이는 배경의 중심과 글자 중심이 5px 어긋나는 현상을 재현했다. 행 높이 통일과 목록 높이 조정, 스크롤 정렬로 해결했다.
- 선택·호버·누름 상태의 행 크기와 세로 중심을 라이트·다크 테마에서 비교한다.
- 방향키·Home·End 이동, 열린 상태의 화면 크기 변경, 마우스·터치 스크롤 후 위아래 행의 잘림을 확인한다.
- 검색 결과가 없거나 복원될 때 목록 크기와 가로·세로 스크롤 초기화를 확인한다.
- 선택 행을 화면 안으로 이동시킬 때 팝업 외곽까지 스크롤되어 제목이 가려지는 경로를 차단한다. 팝업 외곽은 스크롤하지 않고 목록만 스크롤한다.

## 최종 HTML·CSS 검토

현재 디자인을 기준안으로 유지한다. 공통 외형은 `ui.css`, 페이지와 반응형 배치는 `calculator.css`, 의미 구조는 HTML 및 공통 마크업에 나뉘어 있다.

- 본문과 선택창 5종, 기술 조건 팝업에서 단일 main/h1, 한국어 문서 설정, 중복 ID, 레이블·ARIA 참조, 중첩 조작 요소를 확인했다. 참조 오류나 잘못된 중첩은 발견되지 않았다.
- 샘플 CSS 두 파일에 같은 규칙 안의 중복 속성 선언이나 `!important`가 없다. 반응형 재정의와 상태별 스타일은 의도된 범위에서 적용된다.
