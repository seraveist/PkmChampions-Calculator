# Team Synergy Table Plan

이 문서는 남은 메뉴 중 `상성표` 탭을 고도화하기 위한 구현 계획이다.

## Goal

기존의 단순 방어 상성 카운팅을 파티 진단 대시보드로 확장한다.

상성표는 두 가지 모드를 가진다.

- 방어 상성 보기: 파티가 특정 타입 공격을 얼마나 일관되게 허용하는지 점수화한다.
- 공격 타점 보기: 파티의 24개 기술이 어떤 타입 또는 주요 메타 포켓몬을 뚫을 수 있는지 점검한다.

## Party Size Rule

- 0~2마리 입력 상태에서는 진단 결과를 출력하지 않는다.
- 3마리 이상부터 진단한다.
- 이유: Champions 싱글은 6마리 중 3마리 선출이 최소 기준이다.
- 6마리 전체 입력도 지원한다.

## Defensive Consistency Score

각 포켓몬이 특정 공격 타입을 받을 때의 방어 배율을 점수로 변환한다.

| 방어 배율 | 점수 |
| --- | ---: |
| 0배 | 0 |
| 1/4배 | 0.25 |
| 1/2배 | 0.5 |
| 1배 | 1 |
| 2배 | 2 |
| 4배 | 4 |

파티 합산 점수는 최대 `10+`로 표시한다.

권장 판정:

| 합산 점수 | 상태 | 표시 |
| ---: | --- | --- |
| 0.0~4.5 | 안전 | 안전 |
| 5.0~5.5 | 보통 | 보통 |
| 6.0~7.5 | 일관성 허용 | 주의 |
| 8.0~9.5 | 붕괴 위험 | 위험 |
| 10+ | 방어 불가 | MAX |

## Ability Adjustment

특성 보정은 1차와 2차로 나눠 구현한다.

### Phase 1

명확하게 타입 상성을 바꾸는 방어 특성만 우선 적용한다.

예:

- `levitate`: 땅 무효
- `voltabsorb`, `motordrive`, `lightningrod`: 전기 무효
- `waterabsorb`, `stormdrain`, `dryskin`: 물 무효 또는 흡수
- `flashfire`: 불꽃 무효
- `sapsipper`: 풀 무효
- `wellbakedbody`: 불꽃 무효
- `eartheater`: 땅 무효

계산 결과에는 "특성 보정 적용" 표시를 단순하게 남긴다.

### Phase 2

조건부 또는 문맥 의존 특성은 추후 확장한다.

예:

- 날씨, 필드, 아이템, 상태 이상, 접촉 여부가 필요한 특성
- 더블 전용 또는 아군 보정 특성
- Mold Breaker류에 의해 무시될 수 있는 특성

## Meta Threat Lists

메타 리스트는 JSON 파일로 분리한다.

1차 구조는 id 배열만 사용한다.

```json
{
  "defensiveThreats": [
    "fluttermane",
    "gholdengo"
  ],
  "coverageChecks": [
    "dondozo",
    "tinglu"
  ]
}
```

규칙:

- JSON에는 내부 포켓몬 id만 작성한다.
- 화면에는 `PokemonById[id]`로 찾은 한글 이름만 표시한다.
- 없는 id는 렌더링에서 제외하고, 개발용 콘솔 경고만 남긴다.
- 1차 구현에서는 위협 포켓몬의 타입 분석이나 타점 판정까지 강하게 묶지 않는다.
- 이후 확장 시 같은 id 배열을 기반으로 자속 타입 기반 방어 위협 또는 타입 약점 기반 타점 부족 표시를 붙일 수 있다.

방어 상성 모드:

- `defensiveThreats` 목록을 "메타 주의 포켓몬"으로 표시한다.
- 1차 표시는 이름 목록만으로 충분하다.

공격 타점 모드:

- `coverageChecks` 목록을 "타점 점검 포켓몬"으로 표시한다.
- 1차 표시는 이름 목록만으로 충분하다.

## Coverage Mode

공격 타점 모드는 유저가 파티 6마리 각각의 기술 4개를 직접 입력한다.

- 총 24개 기술을 기준으로 18개 타입에 대한 타점 유무를 표시한다.
- 기술 목록은 learnset 기반 드롭다운을 우선 사용한다.
- 필요하면 전체 기술 검색도 허용할 수 있다.
- 기술 타입은 `MoveById`의 현재 데이터에서 가져온다.
- 특성/도구/필드에 의한 타입 변경까지 반영할지는 2차 범위로 둔다.

1차 판정:

- 특정 타입을 2배 이상 찌르는 기술 수 표시
- 0개면 타점 부재
- 3개 이상이면 타점 우위

## UI Requirements

- 포켓몬 변경 시 셀 크기가 흔들리지 않도록 테이블 셀 크기를 고정한다.
- 방어 상성 보기와 공격 타점 보기는 상단 토글로 전환한다.
- 타입별 결과는 18개 타입이 항상 같은 위치에 남아야 한다.
- 파티 슬롯은 6개 고정으로 표시한다.
- 3마리 미만 입력 시 "3마리 이상 입력 시 진단" 상태를 보여준다.
- 결과 패널은 오른쪽 또는 하단에 두고, 위험 타입과 메타 리스트를 한 번에 볼 수 있게 한다.

## Suggested Implementation Order

1. 메타 위협 JSON 템플릿 추가
2. 상성표 상태 모델 정리
3. 방어 상성 점수 계산 함수 추가
4. 3마리 이상 조건부 진단 렌더링
5. 셀 크기 고정 CSS 정리
6. 방어 메타 리스트 이름 표시
7. 공격 타점 모드 상태와 기술 입력 UI 추가
8. 24개 기술 기반 타입 타점 계산
9. 공격 타점 메타 리스트 이름 표시
10. 상태 테스트와 스모크 테스트 추가

## Test Plan

전용 스크립트 후보:

```powershell
npm.cmd run state:matchup
```

테스트 항목:

- 3마리 미만이면 진단 미출력
- 3마리 이상이면 타입별 일관성 점수 출력
- 무효, 반감, 약점 점수 합산 확인
- 특성 보정 Phase 1 확인
- 메타 threat id가 한글명으로 표시되는지 확인
- 없는 메타 id가 렌더링을 깨뜨리지 않는지 확인
- 공격 타점 모드에서 24개 기술 기반 타점 수 계산 확인
- 포켓몬 변경 후 셀 크기/행 수가 유지되는지 스모크 테스트
