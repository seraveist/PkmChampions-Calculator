# 결정력 계산 메뉴 보완 결과

작업일: 2026-09-08. 이전 완성도 분석에서 확인한 우선순위 1·2 항목을 현재 작업 사본에 반영했다. 단독 실행 HTML과 배포용 파일도 다시 생성했다.

## 반영 내용

| 항목 | 보완 결과 |
| --- | --- |
| 탁쳐서떨구기와 회복열매 | 피해 도중 소비되는 반감열매와, 피해 뒤 발동하는 회복열매를 구분했다. 회복열매는 도구 제거 후 발동할 수 없으며 점착으로 유지한 도구는 정상 처리한다. |
| 회복 설명 | KO 분포를 계산하는 경로에서 실제로 적용된 도구·볼주머니 회복을 기록한다. 제거한 도구는 ‘제거 · 이후 회복 없음’으로 안내한다. 회복 반영 표시는 모든 난수에서 회복한다는 뜻이 아니라 회복이 일어나는 경로를 포함했다는 뜻이다. |
| 결과 카드 | 고정 높이와 세 행 고정을 없애고 제목·예외·회복·피해·보정·KO를 내용에 따라 배치한다. 접힌 영역이나 마우스 올리기에 의존하지 않고 모든 보정 설명을 표시한다. |
| 모바일 결과 헤더 | 버튼이 여러 행으로 배치될 때 헤더도 함께 늘어나도록 했다. |
| 쓰러진 아군 | 총대장·성묘 선택 시 양측 입력을 제공한다. 싱글 0~2, 더블 0~3이며 형식 변경·상태 정규화·기본값 복원을 양측에 적용한다. |
| 순풍 | 양측 순풍 입력을 추가해 스피드 및 스피드 의존 기술 조건에 전달한다. 공수교대 시 해당 포켓몬 측 조건을 함께 옮기며 기본값 복원 시 해제한다. |
| 고정 피해 결정력 | 지구던지기·나이트헤드 등은 ‘고정 50’, 부자유친 적용 시 ‘고정 100’처럼 기술 사용 전체의 피해를 표시한다. 의미가 없는 위력 입력은 비활성화한다. |
| 자동·수동 위력 | 직접 입력은 수동 고정으로 명시하고 기술별 자동 복원 버튼을 제공한다. 결과에는 기본/입력 위력과 실제 보정 위력을 함께 표시한다. 빈 입력도 자동 계산으로 복원한다. |
| 연속기 위력 정보 | 메가 집단구타의 반환 위력을 실제 참여자의 기본 종족 공격에 맞췄다. 트리플악셀처럼 타격마다 위력이 다르면 순서대로 표시한다. |
| 모바일 요약 | 난수 KO 확률, 무효 조건 제외, 생존 효과 제외, 생존 후 회복 반영을 함께 전달한다. |
| 계산 기준·적용 조건 | 계산 기준을 접히지 않는 결과 패널에 배치했다. 날씨·필드·벽·순풍·쓰러진 아군·자동 진입 효과 등의 적용 조건을 모아서 보여준다. 무효를 제외한 상성 배지는 ‘계산상’ 배율로 명시한다. |

## 대표 회귀 검증

- 실제 수록 기술 조합인 괴력몬 탁쳐서떨구기 → 잠만보(특성 없음, 최대 HP 235, 현재 HP 150, 자뭉열매): 피해 65~77, 사용 후 HP 73~85, 확정 3타. 잘못된 자뭉열매 회복은 발생하지 않는다.
- 점착·긴장감 및 반감열매+볼주머니의 처리 순서를 별도 검사했다. 수록 포켓몬이 배우는 실제 사례와, 효과 하나를 분리하기 위한 통제용 특성/타격 모형을 검사 이름에서 구분한다.
- 기존 독립 난수, 회복 경계, 연속기, 스피드, 자동 진입 반응 검사에 고정 피해 표시·양측 조건·자동 복원·모바일 확률 검사를 추가했다.
- 브라우저 검사는 1440px·375px·320px에서 일반/무효+회복/연속기+회복/난수 KO/다수 보정/네 기술 결과를 측정한다. 카드 안쪽 요소의 경계와 겹침, 입력 행 경계, 결과 헤더 버튼 경계 및 가로 넘침을 검사한다.
- 320px에서 실제 입력 변경 및 클릭 이벤트로 쓰러진 아군, 순풍, 싱글·더블 전환, 양측 제한, 기본값 복원, 위력 수동 입력과 자동 복원, 고정 피해 입력 비활성화를 검사한다.
- 최종 스크린샷에서 발견한 모바일 기술 행의 실제 요소/배치 선택자 불일치도 수정했다. 위력 입력칸이 인덱스 열로 밀리지 않으며 최소 읽기 너비 검사도 추가했다.

검증 결과: 전체 자동 검사 로그 1,250개 통과, 실패 0개, 기존 건너뜀 17개. 계산기 집중 브라우저 검사 58개 통과, 전체 메뉴 브라우저 검사 85개 통과. 마지막 모바일 CSS 조정 뒤에는 관련 CSS·드롭다운 검사와 양쪽 브라우저 검사를 다시 실행했다. 검사 수는 로그의 통과 항목 수이며 서로 독립인 게임 조합 수를 뜻하지 않는다.

검사: `npm test`, `scripts/calculator-menu-browser-assessment.mjs`, `scripts/browser-layout-smoke.mjs`. 새 브라우저 측정 결과는 `docs/calculator-menu-browser-verification.json`에 저장하며 이전 진단 JSON은 비교 자료로 보존한다.

## 이전 분석의 정정과 범위

이전 분석에서 ‘기본값과 같은 150을 직접 입력하면 수동 고정된다’고 설명한 부분은 실제 UI 이벤트를 재현한 결과가 아니었다. 당시 진단은 내부 상태에 150을 직접 넣었으며, 당시 UI 이벤트는 기본값과 같은 숫자를 자동 계산으로 되돌렸다. 이번에는 **직접 입력하면 명시적 수동 고정, 버튼 또는 빈 입력으로 자동 복원**하는 일관된 동작으로 변경하고 실제 UI 이벤트까지 검증했다.

기준은 결정력 계산이다. 무효·생존 효과는 안내하고 비영 피해 보정과 생존 후 회복을 반영한다. 같은 기술을 같은 입력 조건으로 반복하며 방어측 HP·도구 소비·회복을 갱신한다. 상대 행동, 명중 실패를 포함한 승률, 모든 턴의 자동 변화는 계산 범위가 아니다. 10회 이내 KO를 판정하지 못한 경우에는 계산 한계가 표시된다.

이번에 확인된 보완 항목을 해결한 것이며 모든 포켓몬·특성·도구·기술 조합의 게임 실측 검증을 완료했다는 의미는 아니다. 이전 분석에서 후속 편의 기능으로 구분했던 여러 세팅 저장·내구 형태 동시 비교는 별도 기능이며 이번 수정에 포함하지 않았다.
