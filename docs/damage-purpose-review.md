# 계산 목적 재검토 및 수정 내역

기준: main `94063136a69f2916a1de56f4520ccbbf738627b4`를 새로 clone한 작업 사본. 2026-09-08 사용자 확정 기준을 적용했다. 계산기는 공격 결정력을, 내구 역계산은 실제 관측을 해석한다. 따라서 두 메뉴의 무효 처리 기준이 다르다.

## 확정된 계산 기준

| 효과 | 피해 범위 | 타수 확률·결과 카드 |
| --- | --- | --- |
| 타입 무효, 부유·저수 등, 풍선, 강한 날씨의 무효 | 무효인 배율만 1로 놓고 계산한다. 복합 타입의 나머지 배율은 유지한다. | 무효 원인과 계산에서 제외했다는 사실을 표시한다. 실제 명중·KO 확률을 뜻하지 않는다. |
| 기합의띠·기합의머리띠·옹골참·탈·아이스페이스 | 생존·차단으로 제한하지 않는다. | 생존·차단 효과를 카드에 표시한다. 탈 토글이 입력 HP를 바꾸지 않는다. |
| 멀티스케일·팬텀가드·반감열매 등 | 직접 피해 보정은 적용한다. | 보정 표시. 반복 피해에서 HP 조건을 다시 확인하고 반감열매는 첫 타격 뒤 소비한다. |
| 자뭉열매·오랭열매 | 표시되는 공격 피해를 깎지 않는다. | 피해를 견딘 뒤 발동 조건을 충족하면 1회 회복한다. 단발 KO이면 발동하지 않는다. 긴장감·서투름·숙성도 반영한다. |
| 먹다남은음식 | 표시되는 공격 피해를 깎지 않는다. | 살아남은 공격 사이에 최대 HP의 1/16을 내림하여 회복한다. KO 뒤에는 회복하지 않는다. |
| 진입 피해·잔여 피해·상대의 공격/회복 기술 | 제외한다. | 현재 HP를 직접 입력한다. 특성의 턴 종료 회복, 상대가 공격해야 발동하는 조개껍질방울 등은 자동 진행하지 않는다. |

1타는 기술 1회 사용을 의미한다. 연속기는 타격 사이의 열매 발동을 반영하므로 단발기와 다를 수 있다. 같은 입력 상태에서 공격을 반복하며 상대 행동, 능력치의 자동 상승·하락, 교체, 날씨 지속 턴은 진행하지 않는다.

## 난수와 회복 검증

각 공격의 난수를 독립적으로 합산한다. 최소 필요 횟수와 모든 난수가 KO를 내는 횟수를 구분한다. 표시하는 난수 N타 확률은 N회 이내 누적 KO 확률이다.

| HP 100, 고정 피해 | 회복 도구 | 결과 |
| --- | --- | --- |
| 100 | 자뭉열매 / 먹다남은음식 | 확정 1타, 회복 없음 |
| 50 | 없음 | 확정 2타 |
| 50 | 먹다남은음식 | 확정 3타 |
| 56 | 먹다남은음식 | 확정 2타 |
| 60 | 자뭉열매 | 확정 3타: 100 → 65 → 5 → KO |
| 63 | 자뭉열매 | 확정 2타 |

45~55 피해는 회복이 없으면 난수 2타이다. 구체적인 확률은 16개 피해 난수의 분포에 따라 계산한다. 예를 들어 45와 55만 각각 50% 확률로 나오는 검증용 분포에서는 75%; 먹다남은음식이 있으면 25%이다. 10회까지 탐색하며, 그 범위에서 KO가 불가능하면 `10타 초과`로 표시한다.

## 확인 후 수정한 누락

- H32 미만의 방어·특방 투자 후보를 삭제하던 규칙을 제거했다. H32는 실용적 선호 점수로 유지한다. 성격별 최소 공격/속도/내구 투자 강제 필터도 제거했다.
- 25개 성격을 모두 검색한다. 알려진 반감열매 등 방어 도구를 방어 역계산에 반영하고, 양쪽 피해 관측에서 동일한 도구·특성 후보를 결합한다.
- 비 쓱쓱, 엽록소, 모래헤치기, 눈치우기, 서핑테일, 곡예, 속보 등은 공통 스피드 계산을 사용한다. 날씨 억제·화학변화가스·서투름·고대활성/쿼크차지의 스피드 보정도 확인했다.
- 선후공에서 동속 가능성을 보존하고 트릭룸을 반영한다. 기술 우선도가 다르거나 확인되지 않으면 속도만으로 후보를 배제하지 않는다.
- 타점 분석에서 포켓몬 교체 후 배울 수 없는 기술이 남는 문제, 페어리스킨·촉촉보이스 등 기술 타입 변환이 집계와 표시에서 빠지는 문제를 수정했다.
- 이글이글의 불꽃 공격 보정, 슬로스타트·잠복·투쟁심·플러스/마이너스 조건, 더블의 배터리·파워스폿·프렌드가드 입력을 추가했다.
- 무기력의 발동선을 HP 1/3에서 1/2로, 얼음인분을 방어 능력치 대신 특수 기술 피해 보정으로 수정했다. 팬텀가드를 틀깨기로 무시하지 않도록 수정했다. 진홍빛고동·하드론엔진의 환경 조건과 강한 햇살의 일부 보정을 보완했다.

## 전수 분류와 검증의 범위

[전체 분류표](power-mechanics-audit.md)는 현재 빌드의 특성 316개·도구 149개를 모두 포함한다. 저장소의 Pokemon Showdown 기본 데이터와 Champions 오버라이드, 앱의 계산 규칙을 함께 조사했다. [기계 판독 목록](power-mechanics-audit.json)에는 ID별 규칙과 원본 이벤트가 있다. 새로운 기능을 추가할 때 자동 생성 목록과 회귀 검사를 함께 갱신할 수 있다.

분류표는 모든 포켓몬×기술×특성×도구 조합에 대한 완전성 인증이 아니다. 회귀 검사는 타입 무효 8쌍, 정의된 특성 무효 규칙, 생존·회복·직접 보정, 속도, 역계산의 재현 가능한 누락 사례를 대상으로 한다.

다음 범위는 남아 있다.

- 역계산의 상대 HP 관측은 현재 최대 HP에서 받은 피해 직후, 회복 전을 가정한다. 이미 닳아 있던 상대 HP, 회복 이후 관측, 여러 턴 누적 관측을 한꺼번에 추론하지 않는다.
- 역계산은 데미지에 무관한 노력치 축을 범위로 보여 준다. 표시한 각 축의 범위를 자유롭게 조합해도 모두 관측과 일치한다는 의미는 아니다. 가변 위력·최고 능력치 판정처럼 여러 축이 결합되는 특수 사례에는 추가 검증이 필요하다.
- 아군 플라워기프트·강철정신의 추가 중첩, 다른 아군의 모든 특성을 동시에 조합하는 입력은 완비되지 않았다. 입력한 상태를 넘어서는 도구 재획득·강탈·전달·자동 랭크 변화도 진행하지 않는다.
- 행동 우선도 자체를 바꾸는 모든 특성·확률 도구까지 선후공 관측에서 추정하지 않는다. 그러한 상황에서는 행동 순서를 미확인으로 두어야 한다.

## 도구로서의 판단

계산기는 현재 목적에 맞게 피해와 생존 예외를 분리했고, 회복 도구를 고려하는 타수 비교에 사용할 수 있다. 역계산은 유력한 형태를 좁히는 보조 자료로 가치가 있지만 상위 후보를 정답이나 통계적 사후확률로 읽으면 안 된다. 세부조정은 노력치 투자 비교, 도감은 기본 데이터 조회, 상성표와 타점 분석은 파티의 속성 분포를 보는 용도로 적합하다.

개별 기능의 남은 입력 한계를 고려하면, 이 프로젝트는 유용한 대전 보조 도구이며 완전한 대전 재현기나 자동 상대 형태 판정기로 평가할 대상은 아니다.
