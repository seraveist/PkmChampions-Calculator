## 보완한 연결

- 파동의 방호: 원본의 `Future` 제한을 보완하고 접촉 피해 1/2를 연결했다. 원격·틀깨기 등의 우회 조건도 검증했다.
- 메가갑주무사: 새 원본의 벌레/강철·단단한발톱을 사용한다.
- 메가드닐레이브: 메가폼에 남아 있던 기본형의 숨겨진 특성 슬롯을 제거하고 열교환으로 고정했다.
- 노말주얼: 첫 노말 기술의 위력 1.3배, 같은 기술의 연속 타격에는 유지, 다음 사용에는 소비 상태를 반영한다. 역계산 공방 이후에도 소비 상태와 곡예 발동을 전달한다.
- 풍선: 결정력 계산은 피해를 표시하면서 땅 무효를 별도 표기하고, 실제 관측 역계산에서는 무효를 반영한다.
- 스트린더 로우 거다이맥스: 전투 폼 보완 과정에서 사용 불가 대체 폼이 들어오는 문제를 막았다.

시드 발동으로 오르는 능력치 랭크는 자동 적용하지 않는다. 발동 후 도구를 없음으로 바꾸고 방어/특수방어 +1을 입력하도록 조건 안내를 추가했다. 대파의 급소 발생 확률 역시 KO 확률에 합산하지 않고 급소 조건을 선택하도록 안내한다. 이번 수정은 목록과 위 효과 연결이며, 모든 신규 도구·기술의 턴 진행 효과를 전수 구현했다는 의미는 아니다.

## 수동 보완 방법

`data/overrides/champions-data.json`은 쇼다운 원본 → 챔피언스 모드 병합 이후에 적용한다. 동기화 대상 26개 파일에 포함되지 않아 후속 동기화로 지워지지 않는다.

- `pokemon`, `moves`, `abilities`, `items`, `learnsets`, `formats`에 기존 쇼다운 ID별 변경 필드를 지정한다.
- 사용 가능 상태를 바꾸려면 `isNonstandard: null`을 명시한다. 포켓몬은 `formats`의 `tier`도 `Illegal`이 아니어야 한다.
- 특성 슬롯·종족값·습득 기술과 같은 내부 객체는 해당 필드 전체를 교체한다.
- 잘못된 ID는 빌드를 중단하므로 입력 실수가 조용히 무시되지 않는다.
- 한글 표기와 설명은 기존 `data/ko/*.manual.json`을 사용한다.
- 현재 보완은 파동의 방호 사용 가능 상태와 메가드닐레이브 특성 슬롯 두 가지다. 쇼다운에서 수정되면 해당 보완을 제거할 수 있다.
