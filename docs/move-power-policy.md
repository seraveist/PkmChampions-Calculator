# 결정력·피해·N타 계산 기준 (2026-09-15)

## 화면

기술 선택 → 결정력 | 피해 비율·HP·짧은 HP바 → 확정/난수 N타 순서로 표시한다. 기존 폰트와 공통 CSS를 사용하며 모바일에서는 결정력과 피해 영역을 기술명 다음 줄에 나란히 배치한다. 결정력의 고정피해 값은 `50`처럼 숫자로만 표시한다. 특성·아이템 배지는 `기합의띠`, `탈`, `파동의방호`, `먹다남은음식`처럼 이름만 표시한다. 자속 배율과 난수 확률은 유지한다.

메뉴 전환 중의 일반 페이지 로딩 안내문구는 표시하지 않는다. 로딩 상태의 접근성 속성과 실제 불러오기 실패 메시지는 유지한다.

## 결정력 수치

공격측 능력치 × 보정된 기술 위력 × 자속·공격 보정의 지수다. 방어 실수치나 타입 상성 배율 자체를 곱하지 않는다.

- 내 배분·성격·랭크·특성·아이템·HP·상태·급소·수동 기술 조건과 공격측 필드 보정을 사용한다.
- 상대 배분·성격·랭크·특성·아이템·HP·수동 타입 변경은 사용하지 않는다. 상대 천진·수포·화학변화가스·자동 위협으로 결정력 수치가 바뀌지 않는다.
- 상대는 선택한 종/폼의 기본 타입만 색안경·달인의띠 등 공격측 조건부 배율 판정에 사용한다. 0배는 색안경의 반감 조건에 포함하지 않는다.
- 상대 상세 정보가 필요한 기술은 `—`: 이카사마, 자이로볼/일렉트릭볼, 상대 무게/HP/상태/도구 의존 기술, 일격기 등. 직접 위력을 입력해 해당 의존성을 없애면 그 입력을 사용한다. 이카사마의 상대 공격 능력치 의존성은 수동 위력으로 해결되지 않는다.
- 자동 선후공을 요구하는 기술·애널라이즈는 `—`. 선공/후공을 직접 지정하면 그 조건을 사용한다. 무도한행동과 자동 다운로드처럼 상대 조건이 필요한 특성도 확정 가능한 입력이 없으면 `—`다. 투쟁심은 상대 성별 조건이므로 `—`다.
- 변화기는 `—`. 지구던지기·나이트헤드는 숫자 `50`, 목숨걸기는 내 현재 HP. 카운터 계열은 받은 피해와 분류를 입력해야 수치가 나온다.
- 연속기는 한 번 사용했을 때의 합계다. 타격 수나 위력의 확률 분기는 가중 평균으로 표시한다. 트리플악셀의 타격별 위력, 부자유친, 스킬링크·속임수주사위와 직접 지정한 타격 수를 반영한다.
- 상대 때문에 타격 중 내 특성이 바뀌는 경우는 결정력 수치에 반영하지 않는다. 실제 피해 경로는 기존 타격별 처리를 유지한다.

`estimateMovePower()`는 공격측 입력과 중립적인 방어측 구조만으로 공통 위력·공격 단계를 호출한다. `powerAttackProfile()`을 피해 엔진과 공유하여 타격 수·확률 분기 정의를 일치시킨다. UI는 상대 진입 효과가 적용된 `makeCalcState()`의 공격측 대신 원래 공격측 입력을 전달한다.

## HP바와 N타

- 양측의 능력치·랭크, 상성, 직접 피해 증감 특성·도구·필드 보정을 반영한다.
- **타입 무효는 0 피해와 `무효`로 표시한다.** 지구던지기 대 고스트, 지진 대 비행 등. 배짱·중력 등 명시적 무효 해제 조건은 기존 규칙을 따른다. 절대영도 대 얼음의 타입 제한도 유지한다.
- 특성·도구의 별도 무효·차단·강제 생존 효과는 피해와 N타를 제한하지 않고 배지로 안내한다. 기합의띠, 옹골참, 탈 등이 해당한다.
- 멀티스케일·반감열매·파동의방호처럼 피해를 줄이는 효과는 실제 반영한다.
- 먹다남은음식은 살아남은 기술 사용 사이마다 회복한다. N번째 사용으로 쓰러뜨리면 회복은 N−1번이며, KO 뒤 또는 연속기 타격 사이에는 회복하지 않는다. 이 로직은 기존 구현을 유지했다.
- HP 235 잠만보에게 지구던지기 50: 도구 없음 확정 5타, 먹다남은음식 확정 7타(매회 14 HP, 6회 회복).
- 역계산의 관측 피해 경로 `calculateDamage()`는 특성·도구 무효와 차단을 포함하는 기존 목적을 유지한다.

돌격조끼는 방어 능력치 증가 규칙이 있지만 현재 챔피언스 빌드 데이터에서는 제외되어 있다. 이번 변경으로 수록 범위를 넓히지는 않았다.

## 파동의방호

접촉 공격으로 받는 피해를 절반으로 줄인다. 판정 기준은 물리/특수 분류가 아니라 기술의 `contact` 태그다. 기존 `defensiveFinalMods: [{ flag: 'contact', mod: 'x0_5' }]` 규칙을 유지하고 아래 경우를 회귀 검사에 추가했다.

- 물리 접촉기 및 특수 접촉기 피해 반감
- 비접촉 물리기·비접촉 특수기 및 고정피해는 그대로
- 원격·펀치글러브의 비접촉 처리, 틀깨기·화학변화가스의 특성 무시/억제
- 결정력 지수는 그대로, HP바·N타의 피해 경로와 특성 배지에 반영

## 검증

`npm run calculator:golden`은 기존 계산 재현 검사와 `scripts/move-power-golden.mjs`의 공격측 분리·급소·고정피해·타입 무효·회복·파동의방호 검사를 실행한다. 수록되지 않은 특성 조합이나 기술 조합을 쓰는 일부 검사는 개별 규칙 분리를 위한 통제 사례이며 실제 사용 가능 조합을 뜻하지 않는다.

`npm test`로 구조·데이터·피해·역계산·상태 회귀를 검사하고, `scripts/calculator-remodel-browser.mjs`는 실제 브라우저에서 결정력과 HP 영역의 정렬·기존 폰트·화면 폭·접근성을 확인한다.
